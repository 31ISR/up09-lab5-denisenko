# Приложение Django

> ## Описание
>
> Проект создан для демонстрации навыков и умений работы с Django и демонстрирует умение реализовывать базовые функции для сайта с помощью данного фреймворка

## Реализованные функции
- маршрутизация
- использование шаблонов
- создание, изменние и удаление данных в БД
- админ-панель

## Установка и запуск

> Для установки необходимо скачать файлы из репозитория
>
### Запуск
1. С помощью Bash открыть папку **lab1**
2. Запустить сервер `python manage.py runserver`

*Может потребоваться установить Django и Pillow*

3. Перейти по адресу `localhost:8000/`

## Использование

### Приложение выполняет следующие функции:
- Регистрация пользователя и вход в систему
- Создание постов и сообществ
- Просмотр созданных постов и сообществ
- Переход по ссылкам в приложении

### Страницы
* `/` - Главная страница
* `/about/` - Обо мне
* `/posts/` - Посты
* `/communities/` - Сообщества
* `/register/` - Регистрация
* `/login/` - Войти
* `/new-post/` - Создать пост
* `/new-communities/` - Создать сообщество

### Админ-панель
Админ-панель доступна по адресу `/admin/`. 

Для доступа необходимо:

1. Создать суперпользователя:

```
    python manage.py createsuperuser
```
И указать для него логин и пароль, по которым можно будет войти в админ-панель

2. Войти с логином/паролем суперпользователя

> Администратор может:
> - управлять пользователями
> - создавать, редактировать и удалять посты и сообщества
